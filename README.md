# 🍳 Telma Food - Recipe Collection

A modern web application for discovering and exploring delicious food recipes. Built with Next.js and featuring an intuitive user interface for browsing recipes.

## 📋 Project Overview

**Telma Food Recipes** is a responsive web application that provides users with an easy way to discover, view, and manage food recipes. The project is built with modern web technologies and best practices.

### Tech Stack

- **Frontend:** HTML, JavaScript, CSS
- **Framework:** Next.js
- **Language Composition:**
  - HTML: 57.2%
  - JavaScript: 22.7%
  - CSS: 20.1%

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mohammadhossein-asadi/telmafood.git
cd telmafood
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to [http://localhost:3000](http://localhost:3000)

## 📖 Usage

- Browse through the available recipes
- Search for specific recipes
- View detailed recipe information and instructions
- Responsive design works seamlessly on desktop and mobile devices

## 🛠️ Development

To start editing the application:

1. Modify files in the `app/` directory
2. The app will automatically reload as you make changes
3. Check the browser console for any build errors or warnings
